## 🔧 قابلیت‌های جدید

### ۱. Aim Assist Ultra
- پیش‌بینی حرکت با الگوریتم Kalman
- تشخیص خودکار اسلحه
- ۴ پروفایل هدف (aggressive, defensive, sniper, close_range)

### ۲. Recoil Control
- ۷ اسلحه با الگوی دقیق
- جبران عمودی و افقی
- کنترل Burst و Spray

### ۳. Magic Bullet
- نفوذ دیوار (۳ لایه)
- آسیب ۹۹۹
- دقت ۹۹.۹٪
- پیش‌بینی گلوله

### ۴. Sniper Scope
- زوم پویا (۱x-۱۲x)
- کاهش لرزش ۹۵٪
- دید حرارتی و شب

### ۵. Anti-Detection
- Humanization پیشرفته
- تاخیر تصادفی
- تنوع در آمار
